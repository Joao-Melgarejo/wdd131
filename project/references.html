Referencias

Una lista de las imágenes externas y fuentes de contenido utilizadas en esta página web del proyecto.

Imágenes propias

La mayoría de las imágenes de este sitio web son imágenes originales proporcionadas por el negocio familiar The Master Gasfitería, incluyendo fotos de servicios, el retrato del propietario y el logo.

Imágenes externas

  • tool-1.webp - Imagen de herramientas de gasfitería de una fuente en línea, utilizada con fines educativos.
  • tool-2.webp - Imagen de fuga de agua en tuberías de una fuente en línea, utilizada con fines educativos.

Contenido de texto

Todo el texto de este sitio web fue escrito para este proyecto basado en información real del negocio, proporcionada por el propietario y el estudiante. No se utilizaron fuentes de texto externas.

Tipografía

La tipografía utiliza Playfair Display y Outfit, cargadas desde Google Fonts bajo la Licencia de Fuente Abierta.
